# B站发布说明范本

## 标题建议

B站当前粉丝快照导出与关系变化追踪：浏览器本地脚本

## 正文建议

这是一个在本地浏览器执行的B站粉丝快照工具。它会自动识别当前登录账号，读取当前粉丝总数并分页导出接口实际返回的粉丝明细，不需要手工填写 UID，也不会导出 Cookie、SESSDATA、bili_jct、密码或验证码。

主要功能：

1. 导出当前粉丝 JSON 和 CSV；
2. 保存粉丝 UID、昵称和关注时间；
3. 以后再次运行并导入旧 JSON，可以计算新增粉丝和“关系已消失”候选；
4. 只有扫描前、名单接口、扫描后三个总数一致，且唯一 UID 数精确等于该总数时，结果才会标记为完整；
5. 新旧快照必须都完整、属于同一账号且计数一致，工具才会执行比较。

需要明确说明当前限制：

- 2026-08-08 的一次自有账号实测中，接口报告 1065 名粉丝，但 `/x/relation/fans` 只返回 1000 个唯一 UID，第 21 页为空；
- 当本轮明细少于报告总数时，结果显示 `complete: false`，“导入旧快照”停用，窗口外账号不会被当作“关系已消失”；
- 1000 人停线是对应路由和采集时点的直接观测，不外推为所有客户端、模式和日期都完全一致；
- “关系已消失”可能是主动取关，也可能是注销、封禁、拉黑、平台清理或被移除；
- 本工具不能恢复第一次建立快照以前、且没有旧名单或浏览器缓存的全部历史取关者；
- 这不是B站官方工具。

使用方法：

登录B站后打开个人空间，按 F12 进入 Console，将完整 JS 脚本粘贴运行。右上角出现工具面板后，等待读取完成并保存 JSON。之后定期保存快照，即可比较前后变化。
