# B站发布说明范本

## 标题建议

B站粉丝名单完整导出与取关追踪：无需账号密码的浏览器本地脚本

## 正文说明

这是一段只在本地浏览器执行的B站粉丝快照工具。它会自动识别当前登录账号，动态读取粉丝总数并分页导出，不写死UID、人数或页数。

### 主要功能
1. 导出当前粉丝JSON和CSV；
2. 保存当前粉丝UID、昵称和关注时间；
3. 以后再次运行并导入旧JSON，可以计算新增粉丝和关系已消失的账号；
4. 不导出Cookie、SESSDATA、bili_jct、密码或验证码。

### 需要注意
- 脚本本身没有固定人数上限，但不能绕过B站服务端的展示上限、风控和权限限制；
- 只有实际导出数量达到接口报告总数时，结果才会标记为完整；
- “关系已消失”可能是主动取关，也可能是注销、封禁、拉黑、平台清理或被移除；
- 本工具不能恢复第一次建立快照以前、且没有旧名单或浏览器缓存的全部历史取关者；
- 这不是B站官方工具。

### 使用方法
登录B站后打开个人空间，按F12进入Console，将完整JS脚本粘贴运行。右上角出现工具面板后，等待读取完成并保存JSON。之后定期保存快照，即可比较前后变化。
