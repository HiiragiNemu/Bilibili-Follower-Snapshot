# 自有账号超过 1000 人的脱敏回归证据（2026-08-09）

## 目的

本记录回答两个窄问题：

1. 自有账号粉丝总数超过 1000 时，公开脚本实际取得多少身份明细；
2. 旧版公开脚本是否会让该不完整快照进入差集并产生误导性的 `removed` 列表。

原始 JSON 含账号与粉丝身份，仅保存在私有工作区。本文件只保留聚合计数、时间、接口名、停止原因和原始文件 SHA-256；目标 UID、昵称、粉丝 UID、文件名及带 `vmid` 的 URL 均未写入仓库。

## 采集边界

- 当前快照生成时间：2026-08-08 17:27:01 UTC（新加坡时间 2026-08-09 01:27:01）。
- 比较结果生成时间：2026-08-08 17:27:19 UTC。
- 快照报告版本：`public-2026-08-01-v1.1`。
- 身份名单端点：`x/relation/fans`，普通分页，`ps=50`、`order=desc`。
- 原始 JSON 没有浏览器名称或精确版本字段，因此本记录不补写浏览器族。
- 当前快照 SHA-256：`40715572ee92b80c1cc46e53352d34a3c67bdd35474eb5b4d59e120ce05a0387`。
- 旧版比较 JSON SHA-256：`bd83c60671ce6ad2559d23224bc534979e2b674bf8e9f7d5f4bc7739991869de`。

这些哈希只用于确认本地原始证据未被替换；仓库不包含对应原始文件。

## 直接观测

| 字段 | 值 |
| --- | ---: |
| 扫描前 `/x/relation/stat` 总数 | 1065 |
| 名单接口报告总数 | 1065 |
| 扫描后 `/x/relation/stat` 总数 | 1065 |
| 导出数组长度 | 1000 |
| 唯一 UID 数 | 1000 |
| 第 21 页 | HTTP 200 / B站业务码 0 / 空列表 |
| 停止原因 | 第 21 页返回空列表 |
| `complete` | `false` |
| `serviceDetailLimitLikelyReached` | `true` |

三处报告总数在扫描窗口内一致，但唯一明细比总数少 65。该次自有账号、该端点、该会话的普通分页因此只覆盖了 1000/1065，不具备完整快照资格。

旧版脚本仍接受这份 `complete: false` 的当前快照并生成比较：

| 旧版比较字段 | 值 |
| --- | ---: |
| 旧快照人数 | 963 |
| 当前已取得集合人数 | 1000 |
| `removedCount` | 68 |
| `addedCount` | 105 |
| 已取得集合净变化 | +37 |
| 平台报告总数净变化 | +102 |
| 两种净变化之差 | 65 |

`963 - 68 + 105 = 1000` 只重建了当前**已取得集合**，而 `1065 - 963 = 102` 才是平台报告总数的变化；两者相差的 65 恰好等于 `1065 - 1000` 的未返回明细数。这直接复现了“1000 人窗口滚动后，旧名单成员被旧版差集列入 `removed`”的失效条件。

离线聚合检查还显示，68 条旧版 `removed` 记录中有 65 条的旧关注时间早于当前 1000 人列表的最早关注时间。该分布与倒序时间窗口截断一致，但本记录不据此给任何具体账号标注主动取关或误判。

## 人工操作与身份结论边界

采集后存在部分拉黑等人工关系操作，且部分账号另有实际取关依据。主动取关、拉黑、移除、注销、封禁、平台清理和窗口截断可能共同出现在旧版 `removed` 数组里。因此：

- 本轮 68 条旧版 `removed` 整体视为失效比较结果；
- 不发布逐账号分类，不依据该文件安排解除拉黑或其他账号操作；
- 上述 65 的算术关系和时间分布用于证明比较准入条件存在缺陷，不用于推断每个账号的行为意图。

## 修复要求与验证映射

公开脚本的修复口径是：

1. 扫描前总数、名单接口总数、扫描后总数必须都是有效非负整数且精确一致；
2. 唯一 UID 数必须精确等于一致的报告总数；
3. 当前快照不完整时停用旧快照导入；
4. 文件事件即使由代码触发，仍在差集前复核新旧双方 `complete`、目标 UID、计数、UID 有效性和唯一性；
5. 任一复核失败时清空旧比较状态，不生成 `removed` / `added` 结果；
6. 1065/1000 作为脱敏回归夹具由自动化测试验证会被拒绝。

移动测试脚本在本轮前已经采用严格完整性验证；本轮同步检查公开脚本与移动快照字段的兼容校验，避免完整性元数据被降级解释。
