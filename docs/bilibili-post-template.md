# B站发布说明范本

## 标题建议

B站当前粉丝快照导出与关系变化追踪：浏览器本地脚本

## 正文建议

这是一个在本地浏览器执行的B站粉丝快照工具。它会自动识别当前登录账号，读取当前粉丝总数并分页导出接口实际返回的粉丝明细，不需要手工填写 UID，也不会导出 Cookie、SESSDATA、bili_jct、密码或验证码。

主要功能：

1. 导出当前粉丝 JSON 和 CSV；
2. 保存粉丝 UID、昵称和关注时间；
3. 以后再次运行并导入旧 JSON，可以计算新增粉丝和“关系已消失”候选；
4. 只有实际取得人数达到接口报告总数时，结果才会标记为完整。

需要明确说明当前限制：

- B站粉丝明细接口目前已知最多返回前 1000 名粉丝；
- 当总粉丝数超过 1000 时，工具可以显示准确总数，但只能导出前 1000 名的身份明细；
- 例如总数为 1050 时，第 1001–1050 名无法通过当前接口取得，结果会显示 `complete: false`；
- “关系已消失”可能是主动取关，也可能是注销、封禁、拉黑、平台清理或被移除；
- 本工具不能恢复第一次建立快照以前、且没有旧名单或浏览器缓存的全部历史取关者；
- 这不是B站官方工具。

使用方法：

登录B站后打开个人空间，按 F12 进入 Console，将完整 JS 脚本粘贴运行。右上角出现工具面板后，等待读取完成并保存 JSON。之后定期保存快照，即可比较前后变化。
